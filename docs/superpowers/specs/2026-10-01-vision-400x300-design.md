# Vision 400×300 硬件放大

用户已选择推进此前提出的 400×300 PPA 方案，并授权自动继续实施。

保留 320×240 RGB565 三预览缓冲和 ESP-DL 输入。显示区域及外框变为 400×300，识别框/标签坐标乘 5/4。复用现有 LVGL PPA draw unit，让其直接缩放到 DOUBLE_DIRECT 当前绘制帧缓冲，不增加预览大缓冲，不写当前显示的前缓冲。

仅接管不旋转、pivot=(0,0)、完全不透明、无 mask 的 320×240 RGB565 / 1.25× 图像；其余 UI 保持软件绘制。硬件操作必须完整处于裁剪区和绘制缓冲内，局部裁剪/弹窗/不支持的条件回退软件绘制。PPA 操作期间等待其他 draw unit 完成，并沿用原生逐行 C2M/M2C 同步。放大输出完整覆盖 400×300，包含 LVGL 转换边界取整少算的最后一行/列。

启用 PPA 图片绘制及 64 字节 draw buffer 对齐，先采用 64 字节 PPA burst。持久补丁沿用 apply_managed_component_patches.py，拒绝未知上游源。坏帧拒绝、DMA 缓冲耗尽保护、音频输出和模型尺寸均保持原实现。

验收：真实缩放函数 host 回归覆盖输出参数、完整/局部裁剪、缓冲边界及失败回退；UI/音频/摄像头/Vision 专项检查；IDF 6.1 构建和烧录数据校验；sysmon 验证确实使用 PPA、内存没有新增大帧缓冲、预览流畅，并由用户确认尺寸与画面稳定。
