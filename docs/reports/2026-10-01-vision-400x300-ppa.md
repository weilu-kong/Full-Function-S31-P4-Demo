# Vision 400×300 PPA 预览（2026-10-01）

分支：`codex/vision-ai`；ESP32-S31 Korvo-1，ESP-IDF 6.1。

## 修改

- 显示画面由 320×240 改为 400×300，外框 404×304；画面保持 4:3，面积增加 56.25%。识别框坐标按 5/4 换算，标签保持原字号。
- 相机转换、ESP-DL 输入和三块 RGB565 预览缓冲仍为 320×240，不增加大图缓冲。
- 扩展原生 LVGL PPA 绘制器，只接管完全不透明、无旋转、pivot (0,0) 的 320×240 RGB565 → 400×300 操作。PPA SRM 写入既有 DOUBLE_DIRECT 当前绘制缓冲，阻塞完成后交回 LVGL。
- 保留原生绘制单元的串行交接和完整行 cache 同步；修正该缩放任务的边界及 cache 范围。部分裁剪、弹窗或硬件错误时使用软件回退。
- 使用 64 字节 draw-buffer 对齐及 PPA burst。修正 LVGL 暴露 PPA 私有头文件时所需的传递构建依赖。补丁随依赖解析自动应用，并跟踪补丁文件变化。
- 已有 DVP 短帧拦截、DMA 缓冲耗尽保护、预览所有权与音频处理均保留。

## 验证

- 实际缩放 C 片段 host 编译通过：输入/输出尺寸、scale 1.25、既有 framebuffer 指针与 stride/offset、全块裁剪、边缘位置、短缓冲、PPA 失败回退。
- Synth/BT、LVGL UI、相机 DMA 完整性/耗尽、Vision 服务 host 检查及 `git diff --check` 通过。
- 两次成功 IDF 构建，包括最终构建依赖跟踪复查；独立只读审查无阻塞问题。
- `/dev/cu.usbserial-1120`、920160 baud 烧录完成并通过数据校验；串口连接后成功启动 UI。
- 应用二进制：0xa12f10 字节；应用分区剩余 12%。

## 验证边界

不增加额外图像帧缓冲，但 PPA 客户端/DMA 描述符及 64 字节对齐可能增加少量资源。放大仍增加 PSRAM 读写带宽，部分裁剪时软件回退仍占 CPU。sysmon 的 CPU 百分比伴随 `Not enough time elapsed` 警告，未作为有效 CPU 利用率使用。本轮没有蓝牙音乐遥测，不作为新增 A2DP 连续播放验收；本次持续运行的稳定、流畅已获用户确认；更长时间及其他负载仍可继续观察。既有 Fireworks 基线测试问题不在本次范围内。
