# Korvo-1 UI Shell 与语音 AEC 实施计划

日期：2026-09-09  
状态：按已确认设计推进

## 里程碑 1：工程与状态核心

1. 建立 `firmware/korvo1_yokai_demo`，锁定 ESP-GSP、Korvo-1 no-glib BSP 与 ESP-SR 依赖。
2. 以可在宿主机运行的状态机测试先定义：Home 复位、分页、下拉面板、唤醒后语音监听和命令成功/失败反馈。
3. 用 ESP-GSP bundle 编译 800×480 日文掌机桌面基础场景；将状态机与 UI 控件绑定。
4. 以 `idf.py --preview -DIDF_TARGET=esp32s31 build` 验证编译，不烧录。

验收：核心状态机测试通过；ESP-GSP bundle 与 S31 固件可构建。

## 里程碑 2：桌面、导航与快捷设置

完成桌面两页、Home、触摸点击和左右翻页；完成亮度、音量、Wi-Fi、蓝牙的下拉面板；接入像素素材和状态转场，并在 GSP 模拟器检查 800×480 可读性。

## 里程碑 3：专属应用场景

按已确认场景实现 Synthesizer、天气、语音、物体识别、照明、时钟/计时器、电卓与食材管理。每个页面先建立真实状态和操作控件，再接入相应功能服务。

## 里程碑 4：端侧语音、AEC 与板级验证

1. 初始化 Korvo-1 的 ES8389 音频路径为 16 kHz 全双工。
2. 采集并确认麦克风/播放参考原始声道排序，设定 AFE `input_format`。
3. 校准播放到参考帧的延迟，验证 AEC、VAD、WakeNet 和 `mn7_en`。
4. 在获许可后写入已批准的英语命令词表并连通 App 控制器。

验收：回声环境下日语唤醒稳定、命令状态正确反馈、实体 Home 返回桌面且 WakeNet 常驻。

## 后续目标适配

## 禁止事项

不得复用 S3-Box 项目的美术或页面布局；不得未验证地写死 Korvo-1 声道/延迟；不得在未获许可的情况下烧录、控制外部设备，或自行选择英语命令词表。
