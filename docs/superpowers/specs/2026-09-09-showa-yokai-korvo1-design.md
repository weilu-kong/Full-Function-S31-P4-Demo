# 昭和妖怪掌机 Demo：已确认设计规格

日期：2026-09-09  
状态：已确认，作为实现基线

## 目标与范围

首要目标是为 **ESP32-S31-Korvo-1（800×480）** 制作 ESP-GSP Demo。ESP32-S31 Mosaico 与 ESP32-P4X-Function-EV Board 使用同一应用状态和内容模型，后续按实际屏幕尺寸重排；Korvo-1 先完成。

SDK 基线由项目负责人选择为 ESP-IDF master，固定验证提交 `c712a0dde385d659a1470a136251980d31a70bc1`。图形使用 ESP-GSP 1.2.0；音频和端侧语音使用 ESP-SR 2.5.3 的 AFE。正式阶段仍须在真实开发板上复核。

## 视觉系统

- 主题：昭和掌机风格的日本神话妖怪像素画。
- 主色：深靛蓝和暖米白；每个应用拥有独立强调色。
- 语言：日文功能标签；数字、状态和操作文字在 800×480 原生尺寸可读。
- 共用元素：固定状态栏、像素边框、按钮、两页分页点和底部 Home 区。
- 交互区优先于装饰；装饰不得覆盖控件或把控件伪装成背景。

首轮高保真图位于 `design/yokai-v1`，其中 `DESIGN.md` 定义色彩、排版与动效，`APP-SCENES.md` 定义余下 App 场景。

## 场景与状态

桌面为两页四宫格：第一页为 シンセ、天気、音声操作、物体認識；第二页为 照明、時計・タイマー、電卓、食材管理。

应用进入后保留共用导航，却切换独立场景：雷神太鼓、妖怪村落、言灵神社、目目连观察室、提灯祭街、狸猫钟屋、算盘付丧神、河童厨房。待机轮换三张同世界观完整像素画。

必须实现的状态包括应用翻页、进入/退出、下拉快捷面板、按钮按压和天气/待机画面切换。动效以短时间位移、透明度与纹样变化表现，性能目标需在 ESP-GSP 模拟器和真机上实测确认。

## 已确认的语音与 AEC 架构

- AFE 常驻运行：AEC、降噪、VAD 与 WakeNet。
- 唤醒词：日语 `こんにちは ESP`，模型 `wn9l_ja_konnichihaesp_tts3`。
- 唤醒后打开日文语音界面并开始监听；英语 MultiNet 模型 `mn7_en` 负责命令识别。
- 状态文案依次使用：`呼びかけてください`、`聞いています`、`認識中`、`実行しました`、`聞き取れませんでした`。
- Home 返回初始桌面，不能停止后台 WakeNet。

首版音频数据通道按“两路麦克风 + 播放回声参考”的目标设计，但不得假定 Korvo-1 的实际 I2S slot 顺序或参考延迟。接入前需要记录板级原始采样并完成声道映射和 AEC 延迟校准。
