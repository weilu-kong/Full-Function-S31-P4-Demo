# 昭和妖怪掌机 — 首轮视觉设计

## 交付
六张独立 PNG 原图，见 images；index.html 提供六屏总览和 800×480 CSS 像素显示模式。原图为 ImageGen 输出，保留原始尺寸，不冒充原生设备截图。UI 文字、按钮、滑条和状态在最终固件中必须独立绘制，不能把整张效果图当成可交互 UI。

本轮不编写固件、不连接天气和硬件，不改变旧项目。完整生成提示词见 PROMPTS.md；使用内置 ImageGen，所有参考图均为本轮原创。

## 视觉规范
- 底色 #171c35；文字和边框 #f4e6bc；朱红 #de6651；青绿 #70af9a；金色 #dfb85d。以上为实现目标色值，生成图存在色彩变化。
- 16-bit 像素场景，深色实底信息区。共享状态栏与底部 Home，待机隐藏常规外壳。
- 实现时日文正文目标 18–22 px，标题 24–28 px，触控目标至少 44×44 px；原生像素素材使用整数倍缩放，避免直接缩小高分辨率画面导致像素不均匀。
- 首页入口按 シンセ / 天気 / 音声操作 / 物体認識 排列。第二页为 照明 / 時計・タイマー / 電卓 / 食材管理，后续绘制。
- App 左上 Back 回来源桌面页，Home 关闭覆盖层并回第一页。下拉面板捕获输入，底层不响应。
- 晴天与雨夜保持地理结构和数据布局，天气变化同时更新图标、文字、光照、雨线与角色状态。场景是主题化表达，不是东京实景。

## 动效意图（设计目标，尚未实测）
| 交互 | 时长目标 | 表现 |
|---|---|---|
| 桌面翻页 | 220 ms | 水平平移与减速落位；分页指示同步；不在 App 中误触翻页 |
| 进入 App | 180 ms | 场景短淡入，先保证标题与控件可见；避免大型缩放导致像素模糊 |
| 下拉设置 | 跟手，松手后 180 ms | 面板随手指移动，背景压暗；Home 始终可达 |
| 按键 | 70–100 ms | 边框内移 1–2 px 或换色；释放恢复 |
| 合成器 | 输入立即反馈 | 琴键换色；雷纹短闪；雷神击鼓用少量精灵帧，不每帧重绘整幅插画 |
| 天气变化 | 400 ms | 场景交叉淡入；数据原位更新；雨粒子仅出现在场景区 |
| 待机切图 | 停留 30 s，切换 600 ms | 三幅场景轮播；本轮仅交付第一幅；触摸只唤醒，不穿透操作 |
| Home | 150 ms | 收起覆盖层，回桌面第一页 |

支持减少动效选项时取消粒子与场景过渡。帧率、内存与延迟待锁定 ESP-GSP/编译器版本后在模拟器及 Korvo-1 实测，不承诺本稿已经达到目标帧率。

## 实现时必须修正和确认
- 本稿是平面生成概念图，实际控件几何以数值为准：亮度 70%、音量 45% 和 65% 的填充长度/手柄位置需精确计算，不能直接照搬图中近似位置。
- 合成器生成图的黑键位置不完全符合标准八度；实现必须按 C#、D#、F#、G#、A# 准确定位，保留 E–F 与 B–C 无黑键。
- 导航条与页头在生成图中存在少量尺寸差异，最终以共享组件固定；待机唤醒文字至少达到正文尺寸。
- 六屏日文主标签已目视核对；最终使用真实字体，避免烘焙文字。当前已检查构图与信息层级；未完成设备可读性、触控和性能验收。
- 晴雨画面与连接开关为 DEMO 数据；真实固件分别显示连接中、断线、获取失败和缓存时间，不假装已连接。
- 新工程沿用导航逻辑，不继承 BOX-3 引脚或旧 ESP-GSP 0.2.7 依赖。芯片 target 与开发板 profile 分开选择。
- 本轮确认后继续其余 App、关键状态、另外两幅待机场景和 Mosaico 方屏重排；P4X 按实际屏幕确定分辨率。
