# Korvo-1 天气与 Wi-Fi 体验修复设计

## 范围

修复天气连接后偶发不刷新、顶部时间不对齐、天气背景不按状态切换，以及 Wi-Fi 已保存网络重连、忘记网络、列表标识和密码键盘字号问题。

## Wi-Fi

- 列表格式为 `序号: [锁图标] SSID RSSI`。开放网络保留 `[OPEN]`；安全网络用锁图标，不显示 `*`。
- 仅使用 ESP-IDF STA flash 配置保存最近一次成功连接的网络，不新建多网络凭据库。
- 扫描到该 SSID 时，点选后打开小操作页：`连接` 复用已保存配置并直接 `esp_wifi_connect()`；`忘记此网络` 清空 STA 配置，若正连接则先断开。清除后再次点选会显示密码抽屉。
- 未保存的加密网络仍显示密码抽屉。键盘按键尺寸与触控区域不变，按键字符字体增至当前两倍，且限制在按键矩形内。

## 天气

- 新增透明的 `↻ 更新` 热区；其动作调用已有天气刷新入口。连接获得 IP 时同样触发刷新；失败保留当前 LIVE 数据或 DEMO 数据。
- 顶部时钟是动态标签，每分钟从 SNTP/JST 本地时间刷新；它不再复用“天气最后更新时间”。SNTP 未就绪时显示 DEMO 时间。
- `weather_bg` 根据天气状态切换：晴/多云使用既有晴天雪女图；雨/雪/雷雨使用既有雨天图。
- 多云叠加透明云层作慢速横移；雨、雪、雷雨叠加降水和水面轻微横移。动效不遮挡原画，不新增独立树木摆动。

## 验证

- 宿主机测试：WMO 状态→背景/动效类别、手动刷新、已保存 SSID 判定与忘记后回退密码输入。
- 运行 Wi-Fi/BT 抽屉与字体字符集检查，随后完成 ESP-IDF 全量构建。
- 真机依次验证：连接后刷新、手动刷新、JST 时间、晴/多云/雨切图、保存网络直连、忘记后重新输入密码、放大键盘字符不溢出。
