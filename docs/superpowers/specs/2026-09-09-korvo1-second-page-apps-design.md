# Korvo-1 第二页应用场景设计

## 目标

为「妖怪ポケット」桌面第二页的四个入口补齐可进入的 GSP 场景，保持与第一页四个 App 相同的转场、日文标签、返回方式和小屏可读性。

## 范围

本轮交付四个独立页面：

| 入口 | 页面标题 | 主题与首轮内容 |
| --- | --- | --- |
| 照明 | 照明　提灯の祭り通り | 提灯祭街配色，金色、青色、紫色三种屏幕烟花预览状态；不接实体灯带。 |
| 時計・タイマー | 時計・タイマー　狸の時計屋 | 狸猫钟屋配色，当前时钟、倒计时与状态提示。 |
| 電卓 | 電卓　算盤の付喪神 | 算盘付丧神配色，大数字显示与四行按键布局；首轮仅视觉演示。 |
| 食材管理 | 食材管理　河童の台所 | 河童厨房配色，三种示例食材，以正常、临期、过期状态区分。 |

## 交互与导航

- 桌面第二页四个按钮分别切换到对应场景。
- 所有场景保留「ホーム」按钮，回到桌面第一页。
- 场景切换使用现有的黑场淡入淡出。
- 首轮不引入完整计算、计时持久化、食材编辑或外设灯带控制。

## 实现边界

- 仅使用 ESP-GSP 原生文本、边框、渐变和已嵌入的 Noto Sans CJK JP 字体。
- 不使用全屏位图，避免影响 Korvo-1 启动和显示初始化。
- 每页控制组件数量，优先使用已验证可见的标签和容器边框绘制路径。

## 验证

- 校验每个场景 JSON 的语法与父级索引。
- 构建 ESP32-S31 固件。
- 在 Korvo-1 上验证第二页按钮、四个场景和「ホーム」返回。
