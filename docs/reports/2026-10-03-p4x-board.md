## 固定配置与实现

ESP-IDF master 固定在 `4d59230ddff16327812782151ef0afef202dc6d7`，使用 GCC 16.1、Meson 1.12.1。用户确认有官方屏幕和摄像头；按 [官方 P4X 板卡指南](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32p4/esp32-p4x-function-ev-board/user_guide.html) 配置 v3.1+ 芯片、1024×600 EK79007/GT911 和 SC2336 CSI 摄像头。

- P4 使用 BSP 5.2.3、esp_video/esp_cam_sensor 2.0.1、ESP-Hosted 3.0.9、Wi-Fi Remote 1.6.5；锁文件独立为 `dependencies.esp32p4.lock`。S31 的全部 36 个组件版本与已验收基线一致。
- 生成配置核对通过：P4 最低芯片版本 301、CPU 400 MHz、PSRAM 200 MHz、16 MB Flash 80 MHz、禁用 Flash auto-suspend、双 LCD 帧缓冲、禁用 Classic BT。这些是编译配置，尚未实测 P4 内存和帧率。
- 显示使用物理 1024×600 双帧缓冲，原有 800×480 内容区居中（112,60）。屏幕切换、浮层和触摸坐标沿用现有流程；Fireworks 的触摸与绘制坐标已补偿偏移，不增加全屏离屏合成缓冲。
- CSI 通过 ISP 请求并检查 RGB565；S31 原有 DVP/UYVY 路径保留。单个 SC2336 IPA 配置可在含空格的项目路径构建；增加多个传感器配置时需要修改上游 CMake 的参数拼接。
- ES8311 采用共享输入/输出 codec，单声道采集与输出、软件 ASRC；混音/AEC 参考保留双声道，写 codec 前再转换为单声道。目标补丁将官方 BSP 的 codec 工作模式改为 BOTH，避免后续采集关闭播放所有者。
- C6 的 SDIO 使用 P4 CLK18/CMD19/D0–D3 14–17、复位54。Hosted 不占用用于 MicroSD 的内部 LDO4。Classic A2DP 在 P4 页面提示不可用，未增加 BLE 应用功能。

## 重现与本地文件

两个目标使用独立 checkout，避免 Component Manager 替换目标专属组件。导出上述 SDK 并将 Meson 1.12.1 放入工具路径后，在 `firmware/korvo1_yokai_demo` 执行：

```sh
idf.py --preview -B build-p4x-master -DSDKCONFIG=build-p4x-master/sdkconfig -DIDF_TARGET=esp32p4 build
python3 test/run_host_checks.py
python3 tools/check_firmware_size.py build-p4x-master
```

S31 使用独立 checkout，把构建目录替换为 `build-s31-check`、目标替换为 `esp32s31`，其余检查相同。

配套 C6 直接复用已解析的 `managed_components/espressif__esp_hosted/examples/wifi/sta/cp` 官方示例，复制到独立目录，只将 `main/idf_component.yml` 中 Hosted 版本固定为 `==3.0.9`，再运行：

```sh
idf.py -B build-c6 -DSDKCONFIG=build-c6/sdkconfig -DIDF_TARGET=esp32c6 build
```

生成配置已确认 `ESP_HOSTED_CP_FOR_MCU`、`ESP_HOSTED_CP_RPC_V2`、`ESP_HOSTED_CP_FEAT_WIFI`、`EH_TRANSPORT_CP_SDIO` 启用；C6 CLK19/CMD18/D0–D3 20–23 与官方线路匹配。

项目本地 `build-p4x-master/validation/` 保存 `build-summary.json`、三种目标镜像、ELF/map、配置、烧录参数、日志，以及 C6 官方示例源文件；C6 包含 `ota_data_initial.bin`。这些生成文件被 Git 忽略。源码与 CI 矩阵已修改，分支未推送，因此上述结果为本地检查，尚无该分支的远端 CI 结果。
